# Dino Heroes

TBS navigateur inspiré des trois piliers de Heroes of Might and Magic III
(carte d'aventure, combat hex, villes), thème dinosaures **original**.

Pas un clone : aucun nom, sprite, carte ou faction Ubisoft.
